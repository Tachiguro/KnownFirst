- **Unknown derived evidence retention:** when a derived candidate is decided `UnknownBacklog`, its owning `ReviewCandidateEntity` and `DerivedTermEvidenceEntity` row(s) now survive normal review-session completion, so Preparation can still recover a real source-compound context. Known/Ignored derived candidates and every Direct candidate continue to be cleaned up exactly as before.
- **Sentence/document dependency protection:** the `Document` and exact `SentenceSpan` a surviving evidence row depends on are now protected from generic maintenance cleanup (document/sentence-span sweeps reached from any unrelated review or preparation completion elsewhere in the app), scoped through the real candidate→session→document/sentence foreign-key relationships. Genuinely unreferenced documents/sentences with no retained evidence remain fully cleanup-eligible.
- **Preparation source-compound context fallback:** both the review-words display path and the Accept path now build context from the retained evidence's real whole-compound source span (never a fabricated component occurrence) when zero valid ordinary occurrence contexts remain, and agree with each other on when that fallback activates.
- **Cleanup on MarkKnown/Exclude:** when the retaining word leaves the Unknown lifecycle, its retained evidence and owning candidate are deleted at that point, scoped to exactly that word.
- **Portable V2 filter (superseded by Package 5A-2, see below):** on merged Package 5A, the portable/full-backup snapshot capture identified which captured `ReviewCandidates` own retained derivation evidence (Schema-11-only, internal enrichment, never itself exported) and the V2 mapper excluded exactly those specific candidate rows from exported review-workflow items, so a Completed session would not leak a provenance-less item.
