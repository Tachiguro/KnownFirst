## Release status and evidence

The user confirmed that KnownFirst `1.0.0-beta.12` (build `12`) was uploaded to Google Play Internal Testing, distributed to testers, installed on an Android device, and tested.

The installed application displayed the build identity string `1.0.0-beta.12 · Release · Build 12 · Commit cfbaee6a (DIRTY)`. Therefore, the exact built source tree cannot be proven from the clean commit identity alone. This evidence does not establish whether the base commit existed on GitHub or which files differed. The exact source commit, clean source tree, and original Google Play upload/distribution dates are unrecorded and unverified.

The presence of a local AAB file in the repository artifacts folder (`KnownFirst-1.0.0-beta.12-code12.aab`) shows a package was built locally, but does not provide cryptographic proof of byte-identity with the package distributed through Google Play.
